# Libron

Web font files for Libron, our main typeface. Libron is not published on any
package registry or font CDN, so these files were built from source and
committed here.

- Source: https://github.com/nicoverbruggen/libron
- Version: 0.30 (commit 15d764e)
- Files: `out/web/*.woff2` from the upstream build

Libron is licensed under the SIL Open Font License 1.1 (see `OFL.txt`). That
license must stay alongside these files.
